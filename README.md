# Vendors-Risk-Analysis
## Project Overview

This project analyzes vendor risk distribution and vendor ranking using Microsoft Excel and Power BI.

The objective of the dashboard is to evaluate vendors based on their risk levels and identify high-risk and low-risk suppliers. The dashboard provides insights into how risk is distributed across vendors and highlights the vendors that require closer monitoring.

The analysis helps organizations improve vendor management and reduce supply chain risks.

## Business Problem

Organizations working with multiple vendors must evaluate supplier risk to ensure operational stability.

Without proper analysis, it becomes difficult to:

• Identify high-risk vendors

• Monitor vendor reliability

• Compare vendor risk levels

• Prioritize vendor management actions

This project builds an interactive Power BI dashboard to visualize vendor risk distribution and vendor rankings.


## Key Performance Indicators (KPIs)

The dashboard focuses on the following metrics:

• Total Vendors

• High Risk Vendors

• Medium Risk Vendors

• Low Risk Vendors

• Top Ranked Vendors


## Dashboard Components

The Power BI dashboard contains the following visualizations:

1. Risk Distribution Chart
   Shows how vendors are distributed across different risk categories.

2. Vendor Ranking Table
   Displays vendors ranked based on their risk scores.

3. Risk Category Breakdown
   Provides a clear view of the number of vendors in each risk level.

4. Vendor Comparison
   Allows comparison of vendors based on their risk scores.


## Key Insights

The analysis provides the following insights:

• Identification of vendors with the highest risk levels

• Clear distribution of vendors across risk categories

• Ranking of vendors based on risk score

• Ability to prioritize vendor monitoring and risk mitigation
